Wrap the ML Pipeline in a Stored Procedure :

CREATE PROCEDURE dbo.RunDataAnalysisPipeline
AS
BEGIN
    SET NOCOUNT ON;

    EXEC sp_execute_external_script
        @language = N'Python',
        @script = N'
import pandas as pd
from sklearn.linear_model import LinearRegression

# 1. SQL Server passes the query results into "InputDataSet" automatically
df = InputDataSet

# 2. Basic Feature Processing & Modeling
X = df[["Feature1", "Feature2"]]
y = df["TargetVariable"]

model = LinearRegression()
model.fit(X, y)

# 3. Generate Predictions for the application
df["Predicted_Values"] = model.predict(X)

# 4. Pass the modified DataFrame back to SQL Server
OutputDataSet = df
'
        ,@input_data_1 = N'SELECT Feature1, Feature2, TargetVariable FROM dbo.AnalyticsSourceData'
        -- Optional: Save the output results directly into an analytical destination table
        WITH RESULT SETS (([Feature1] FLOAT, [Feature2] FLOAT, [TargetVariable] FLOAT, [Predicted_Values] FLOAT));
END;
GO

2. How to Edit (ALTER) the Code 
If you try to execute the exact same CREATE PROCEDURE script 
a second time to update your code, SQL Server will throw an error stating that the object 
already exists.To modify your existing logic, you must change the very first word of your 
script from CREATE to ALTER.For example, if you want to update your pipeline to handle missing 
data before training, you would change it like this:

-- Use ALTER instead of CREATE to update the existing procedure
ALTER PROCEDURE dbo.RunDataAnalysisPipeline
AS
BEGIN
    SET NOCOUNT ON;

    EXEC sp_execute_external_script
        @language = N'Python',
        @script = N'
import pandas as pd
from sklearn.linear_model import LinearRegression

df = InputDataSet

# --- NEW EDIT: Drop rows with missing values before modeling ---
df = df.dropna(subset=["Feature1", "Feature2", "TargetVariable"])

X = df[["Feature1", "Feature2"]]
y = df["TargetVariable"]

model = LinearRegression()
model.fit(X, y)

df["Predicted_Values"] = model.predict(X)
OutputDataSet = df
'
        ,@input_data_1 = N'SELECT Feature1, Feature2, TargetVariable FROM dbo.AnalyticsSourceData'
        WITH RESULT SETS (([Feature1] FLOAT, [Feature2] FLOAT, [TargetVariable] FLOAT, [Predicted_Values] FLOAT));
END;
GO

Once you highlight this script and press Execute (F5), SQL Server instantly overwrites the old code inside 
the database with your updated Python logic. Your scheduled SQL Server Agent Job will automatically start 
using the updated version during its next run.
